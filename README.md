# 🌌 CosmosBox — 3D 天体物理宇宙沙盒

基于 **React 19 + TypeScript + Three.js + Zustand + Web Audio API** 打造的浏览器端 3D 实时天体物理宇宙沙盒。融合高精度双精度 N 体引力引擎、NASA/ESO 2K 真实行星纹理与自定义 GLSL 体积着色器，在浏览器中以流畅 **60 FPS** 沉浸式重演宇宙奇观。

---

## ✨ 核心特性

### 1. 高精度天体物理引擎
- **Float64 速度 Verlet 辛积分 + 自适应子步长**：长时间运行轨道稳定、能量守恒，并结合浮动原点（Floating Origin）技术彻底消除深空大尺度坐标抖动。
- **碰撞融合、灾难性碎裂与洛希极限潮汐撕裂**：高速撞击激发熔岩裂纹与碎片云；卫星闯入洛希极限被潮汐撕裂并自动演化为行星光环。
- **多恒星热力学与气候演化**：实时计算辐射平衡温度、非线性失控温室效应、冰球地球冻结与宜居指数（0–100%）。
- **恒星演化与致密双星引力波**：恒星质量实时映射光谱与光度；支持超新星爆发坍缩为脉冲中子星或黑洞，以及双黑洞/双中子星引力波旋进并合与千新星（Kilonova）。
- **3,200 颗恒星级星系碰撞**：独立粒子星系动力学引擎，实时模拟银河系与仙女座旋涡星系碰撞拉出潮汐尾。

### 2. NASA / 电影级 3D 着色器与天文奇观
- **真实 2K NASA 行星资产**：地球（昼夜灯火、3D 云层、海洋镜面反射、法线起伏、瑞利晨昏线）、月球、太阳与太阳系八大行星、卡西尼土星光环与 2K 银河星空背景。
- **卡冈图雅黑洞引力透镜**：单通道 60 步 RK2 零测地线光线步进，真实扭曲 2K 银河背景形成爱因斯坦环，配合多层流体吸积盘与多普勒增亮。
- **NASA 级 3D 体积光线步进地球极光**：单通道热层球壳体积步进 + 二阶旋度扭曲各向异性羽丝光幕（557.7 nm 翠绿核心 + 630.0 nm 绯红顶晕），支持实时调节地磁暴指数（Kp 0–9）与一键 G5 极光大爆发。
- **太阳风暴（CME）与地球磁层联动**：三段式螺旋日冕磁通量绳弧跨空间飞向地球，撞击后浮现 NASA SVS 级 3D 偶极与磁尾磁力线并自动引爆地球 G5 级南北极光。
- **黑洞潮汐撕裂恒星（TDE）与耀变体喷流**：恒星掠过黑洞被拉成炽热螺旋等离子体流带（意大利面化），同步点亮两极相对论性准直耀变体喷流。
- **密近双星洛希瓣吸积气桥与 Ia 型超新星**：红巨星持续向致密白矮星输送发光气桥，实时追踪钱德拉塞卡极限（$1.44\,M_\odot$），越界即触发热核超新星大爆发。
- **实时日全食 / 血月月食 & 物理双尾彗星**：精确球体本影/半影与地球大气红移血月；罗塞塔 67P 双叶暗黑彗核 + 翠绿 $C_2$ 彗发 + 多射线湛蓝离子尾与丝滑弯曲尘埃尾。
- **3D 时空弯曲网格与螺旋引力波涟漪**：实时可视化质量凹陷与双黑洞/双中子星向外传播的阿基米德螺旋引力波。

### 3. 沉浸交互、音频与持久化
- **自由投放与轨道预测**：一键选择行星、彗星、恒星、黑洞模板，支持自动圆轨入轨与弹弓拖拽发射（带实时轨道虚线预览）。
- **地表第一人称观景（`V`）与电影自动巡航（`C`）**：降落星球表面 360° 仰望地平线、日食或极光夜空，或一键开启全场景平滑运镜巡航。
- **程序化 Web Audio 宇宙音效**：深空氛围合成器 + 碰撞轰鸣、潮汐撕裂、超新星爆发、LIGO 引力波啁啾（Chirp）与太阳风暴音效。
- **时间快照与 JSON 存档**：随时打快照回溯时间点、本地保存/导入导出自定义宇宙存档，以及一键无 UI 高清截图。

## 🚀 快速启动

> 建议使用 **Node.js >= 20**（推荐 Node 22/24）。

```bash
# 安装依赖
npm install

# 启动本地开发服务器（支持 localhost 与局域网 IP 访问）
npm run dev

# 类型检查与生产构建
npm run build

# 预览生产构建产物
npm run preview
```

## ⌨️ 常用快捷键

| 快捷键 | 功能 |
| :--- | :--- |
| `Space` | 暂停 / 继续物理模拟 |
| `R` | 重置当前预设场景 |
| `V` | 进入 / 退出选中天体的地表第一人称观景视角 |
| `C` | 开启 / 退出电影级自动巡航 |
| `G` | 显示 / 隐藏 3D 时空弯曲网格与引力波 |
| `L` | 显示 / 隐藏天体浮动标签 |
| `H` | 隐藏 / 显示 HUD 界面（纯净观星） |
| `Esc` | 退出特殊镜头模式 / 关闭弹窗 / 取消选中 |

## 🛠️ 技术栈

- **前端框架**：React 19, TypeScript 5.8, Vite 6
- **3D 渲染**：Three.js（自定义 GLSL 着色器 + 半分辨率 HDR UnrealBloom）
- **状态管理与图标**：Zustand 5, Lucide React
- **音频引擎**：原生 Web Audio API 实时程序化合成
