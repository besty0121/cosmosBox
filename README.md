# 🌌 CosmosBox — 3D 天体物理宇宙沙盒

基于 **React 19 + TypeScript + Three.js + Zustand + Web Audio API** 打造的浏览器端 3D 实时天体物理宇宙沙盒。融合高精度双精度 N 体引力引擎、NASA/ESO 2K 真实行星纹理与自定义 GLSL 体积着色器，在浏览器中以流畅 **60 FPS** 沉浸式重演宇宙奇观。

---

## ✨ 核心特性

### 1. 高精度天体物理引擎
- **Float64 速度 Verlet 辛积分 + 自适应子步长**：长时间运行轨道稳定、能量守恒，并结合浮动原点（Floating Origin）技术彻底消除深空大尺度坐标抖动。
- **碰撞融合、灾难性碎裂与洛希极限潮汐撕裂**：高速撞击激发熔岩裂纹与碎片云；卫星闯入洛希极限被潮汐撕裂并自动演化为行星光环。
- **多恒星热力学与气候演化**：实时计算辐射平衡温度、非线性失控温室效应、冰球地球冻结与宜居指数（0–100%）。
- **恒星演化与致密双星引力波**：恒星质量实时映射光谱与光度；支持超新星爆发坍缩为脉冲中子星或黑洞，以及双黑洞/双中子星引力波旋进并合与千新星（Kilonova）。
- **3,200 颗恒星级星系碰撞**：独立粒子星系动力学引擎，实时模拟银河系与仙女座旋涡星系碰撞拉出潮汐尾。

### 2. NASA / 电影级 3D 着色器与天文奇观
- **真实 2K NASA 行星资产与深空星野**：地球（昼夜灯火、3D 云层、海洋镜面反射、法线起伏、瑞利晨昏线）、月球、太阳与太阳系八大行星、卡西尼土星光环、2K 银河背景与 **12,000 颗**无限深空多光谱恒星场。
- **创生之柱（鹰状星云 M16 · 3D 体积星云）**：基于 ESO MUSE 三维空间结构观测与 Hubble / JWST 实拍对照，构建三座立体错落的光年尺度冷分子尘埃柱、左上方电离源星团 **NGC 6611**、紫外光蒸发泛光边缘与内部红宝石原恒星及 HH 喷流；支持 **哈勃可见光 (HST) / 韦伯近红外 (NIRCam) / 韦伯中红外 (MIRI)** 一键切换、连续红外尘埃穿透滑动条与 4 个快捷三维视角。
- **仙女座星系（M31）与伴星系 M32 / M110**：基于 NASA / Hubble 实拍参照打造，采用 GPU **2K（`2048×2048`）**对数旋臂流线与分形尘埃纹理烘焙、三区间 3D 核球/厚盘 ACES Filmic 体积渲染，配合 **4 万颗** M31 成员星点（支持赤道面光线求交物理消光及远距光通量平滑衰减）；支持**光学实拍 / 红外尘埃环 / 紫外星环**三波段切换、尘埃消光调节与 **4 个快捷观测视角**（`77°` 地球视角 / 俯视星系盘 / 侧视尘埃带 / 核球特写），以及远柔近锐的 M32、M110 矮椭圆伴星系。
- **广义相对论强引力透镜（爱因斯坦环与十字）**：前景引力透镜星系团实时光偏折成像，支持调节透镜质量与外部剪切率将背景星系弯折为 **360° 爱因斯坦环** 或 **四重爱因斯坦十字**，并支持在天体目录中独立聚焦观测**遥远背景旋涡星系（`z ≈ 3.2`）**。
- **木星—木卫一（Io）火山与等离子体环**：再现木卫一在拉普拉斯潮汐共振下的活火山热点与伞状羽流、绕木星发光等离子体环、磁通量管及木星两极极光足迹（含木卫二欧罗巴、木卫三盖尼米德）。
- **卡冈图雅黑洞引力透镜**：单通道 60 步 RK2 零测地线光线步进，真实扭曲 2K 银河背景形成爱因斯坦环，配合多层流体吸积盘与多普勒增亮。
- **🌀 可穿越虫洞（Morris-Thorne / Ellis 时空星门）**：无事件视界球形弯曲时空传送门，采用 60 步 RK2 莫里斯-索恩零测地线实时光线追踪——晶球外缘折射本宇宙银河与邻近天体爱因斯坦环，喉内 360° 立体透视彼岸宇宙（创生之柱 M16 / 仙女座 M31 / 卡冈图雅黑洞 / 土星环轨道）；穿越时触发 `1,200` 束深空 3D 径向向后飞掠星线、动态 FOV 拉伸与正向穿出过渡（无遮挡塑料环与泛白过曝），配合时空网格对称喉部凹陷、无破坏性引力豁免、自由投放星门模板至任意场景、实时调节喉部半径 $b_0$ 与喉管长度 $a$，以及 **6 自由度飞船 (`F`) 亲身穿喉跃迁**，并在抵达宇宙自动生成双向返回星门。
- **NASA 级 3D 体积光线步进地球极光**：单通道热层球壳体积步进 + 二阶旋度扭曲各向异性羽丝光幕（557.7 nm 翠绿核心 + 630.0 nm 绯红顶晕），支持实时调节地磁暴指数（Kp 0–9）与一键 G5 极光大爆发。
- **太阳风暴（CME）与地球磁层联动**：三段式螺旋日冕磁通量绳弧跨空间飞向地球，撞击后浮现 NASA SVS 级 3D 偶极与磁尾磁力线并自动引爆地球 G5 级南北极光。
- **黑洞潮汐撕裂恒星（TDE）与耀变体喷流**：恒星掠过黑洞被拉成炽热螺旋等离子体流带（意大利面化），同步点亮两极相对论性准直耀变体喷流。
- **密近双星洛希瓣吸积气桥与 Ia 型超新星**：红巨星持续向致密白矮星输送发光气桥，实时追踪钱德拉塞卡极限（$1.44\,M_\odot$），越界即触发热核超新星大爆发。
- **实时日全食 / 血月月食 & 物理双尾彗星**：精确球体本影/半影与地球大气红移血月；罗塞塔 67P 双叶暗黑彗核 + 翠绿 $C_2$ 彗发 + 多射线湛蓝离子尾与丝滑弯曲尘埃尾。
- **3D 时空弯曲网格与螺旋引力波涟漪**：实时可视化质量凹陷、虫洞喉部时空漏斗与双黑洞/双中子星向外传播的阿基米德螺旋引力波。

### 3. 沉浸交互、音频与持久化
- **自由投放与轨道预测**：一键选择行星、彗星、恒星、黑洞与可穿越虫洞模板，支持自动圆轨入轨与弹弓拖拽发射（带实时轨道虚线预览）。
- **自由飞船巡航模式（`F`）**：6 自由度惯性阻尼飞船操控（`WASD` 前后左右推进、`Q/E` 垂直升降、左键拖拽转向、右键拖拽滚转、滚轮 8 挡指数变速、`Shift` 三倍冲刺、`X` 惯性刹车），配合浮动原点重定位可无裁剪穿行土星光环、木卫一羽流、仙女座银盘与创生之柱峡谷。
- **🎥 关键帧运镜脚本与 MP4 / WebM 天文短片录制（`K`）**：内置向心 Catmull-Rom 样条曲线 + 四元数 SLERP 导演运镜器，自动追踪动态天体浮动原点并支持 FOV 与时间流速对数平滑插值；支持各场景一键智能分镜（默认保留当前选定波段与光学/红外参数，手动按 `K` 记录的机位亦可独立捕获并过渡多波段、极光强度与引力透镜剪切率）、`.director.json` 脚本导入导出，以及支持原生 **MP4（H.264 全平台/苹果/微信通用）/ WebM** 双格式切换（不支持原生 MP4 时自动回退 WebM）、`720p` / `1080p` / 窗口分辨率、30/60fps、可选 Web Audio 混音的**无 UI 纯净画布短片直出**（含自由录屏）。
- **🔭 虚拟深空天文摄影模式（`T`）**：模拟真实深空天文摄影管线——切换 5 种望远镜光学系统（目镜直视、哈勃 4 芒十字、韦伯 6+2 六角镀金色散星芒、牛顿反光 45° 四叶星芒、APO 复消色差折射）与 5 种滤镜通道（L-RGB / SHO 哈勃调色 / Hα / O III / NIR），支持等效焦距变焦（200–2400mm）、调焦环离焦散景、圆形目镜视场与十字丝、ISO / 单帧曝光 / Bortle 1–9 光害模拟、赤道仪跟踪开关与 **GPU 乒乓多帧长曝光堆栈降噪**；支持定格后无损 Asinh 曲线拉伸与黑场校准，并可一键导出带 **天文台拍摄参数铭牌** 的高清成片（PNG）。
- **克制细线选中准星与特种镜头**：采用低调细线天体选中准星（近距观察表面、极光或日珥细节时自动淡隐）；支持地表第一人称观景（`V`）与全场景电影自动巡航（`C`）。
- **程序化 Web Audio 宇宙音效**：深空氛围合成器 + 碰撞轰鸣、潮汐撕裂、超新星爆发、LIGO 引力波啁啾（Chirp）、太阳风暴与虫洞时空跃迁音效。
- **时间快照与 JSON 存档**：随时打快照回溯时间点、本地保存/导入导出自定义宇宙存档，以及一键无 UI 高清截图。

## 🚀 快速启动

> 建议使用 **Node.js >= 20**（推荐 Node 22/24）。

```bash
# 安装依赖
npm install

# 启动本地开发服务器（支持 localhost 与局域网 IP 访问）
npm run dev

# 类型检查与生产构建
npm run build

# 预览生产构建产物
npm run preview
```

## ⌨️ 常用快捷键

| 快捷键 | 功能 |
| :--- | :--- |
| `Space` | 暂停 / 继续物理模拟 |
| `R` | 重置当前预设场景 |
| `V` | 进入 / 退出选中天体的地表第一人称观景视角 |
| `F` | 进入 / 退出 6 自由度**自由飞船巡航模式**（飞船内支持 `WASD`/`QE` 推进、左拖转向、右拖滚转、滚轮 8 挡变速、`Shift` 加速、`X` 刹车） |
| `C` | 开启 / 退出电影级自动巡航 |
| `K` | 在运镜面板开启时，将当前视角记录为关键机位 |
| `T` | 开启 / 退出虚拟深空天文摄影模式（望远镜目镜与长曝光堆栈） |
| `G` | 显示 / 隐藏 3D 时空弯曲网格与引力波 |
| `L` | 显示 / 隐藏天体浮动标签 |
| `H` | 隐藏 / 显示 HUD 界面（纯净观星） |
| `Esc` | 停止录制 / 退出特殊镜头模式 / 关闭弹窗与面板 / 取消选中 |

## 🛠️ 技术栈

- **前端框架**：React 19, TypeScript 5.8, Vite 6
- **3D 渲染**：Three.js（自定义 GLSL 体积/零测地线/粒子着色器、GPU 2K 纹理烘焙、乒乓长曝光堆栈管线 + 半分辨率 HDR UnrealBloom）
- **状态管理与图标**：Zustand 5, Lucide React
- **音频引擎**：原生 Web Audio API 实时程序化合成
